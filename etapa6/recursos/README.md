# Recursos lingüísticos congelados

- stopwords_es.txt: lista Spanish de NLTK Data (Snowball), recuperada de https://raw.githubusercontent.com/nltk/nltk_data/gh-pages/packages/corpora/stopwords.zip
- positive_words_es.txt y negative_words_es.txt: diccionarios españoles distribuidos por Orange Multilingual Sentiment, https://file.biolab.si/files/sentiment/

Se conservan para reproducir exactamente esta ejecución. No son etiquetas humanas ni resuelven ironía. Los hashes constan en resultados/verificados/youtube_texto.json. Consultar la atribución de cada colección en sus fuentes; la inclusión no implica autoría del equipo.
